# ผังการทำงานระบบ (PDF)

`AI-Smart-Classroom-System-Diagrams.pdf` — เอกสารภาพรวมทางเทคนิค 7 หน้า:
สถาปัตยกรรม · เส้นทางการเขียนหนึ่งครั้ง · ชั้นของสิทธิ์ · สายการแจ้งเตือน ·
ความสัมพันธ์ของข้อมูล · บทบาทและขั้นตอน deploy

## สร้างใหม่

```bash
node scripts/render-diagrams.mjs
```

อ่าน `diagrams.source.html` แล้วพิมพ์เป็น PDF ผ่าน Chrome ที่ติดตั้งอยู่ในเครื่อง
(ขับด้วย Playwright ซึ่งเป็น devDependency อยู่แล้ว) ต้องต่อเน็ตครั้งแรกเพื่อโหลดฟอนต์ Noto Sans Thai

แผนภาพทั้งหมดเป็น **inline SVG ที่เขียนมือ** ไม่ใช่ Mermaid — เพื่อให้ควบคุมการวางตัวอักษรไทยได้
และไม่ต้องรอไลบรารีเรนเดอร์เสร็จก่อนพิมพ์ ซึ่งเป็นสาเหตุที่ PDF ออกมาเป็นหน้าว่างบ่อย ๆ

แก้เนื้อหาที่ `diagrams.source.html` แล้วรันคำสั่งข้างบนใหม่ · อย่าแก้ PDF โดยตรง
