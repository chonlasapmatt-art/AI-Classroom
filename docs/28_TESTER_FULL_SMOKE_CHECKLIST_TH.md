# Smart Classroom · Full Smoke Test สำหรับ Tester

เอกสารนี้ใช้ตรวจระบบหลัง build ใหม่ โดยเริ่มจาก Preview เพื่อทดสอบข้อมูลเทียมก่อน แล้วจึงทำ smoke test กับ Supabase ของโรงเรียนจริงเมื่อมีบัญชีทดสอบแยกแล้ว

## A. เปิด Preview แบบปลอดภัย

1. ใช้ dev build ที่ตั้ง `VITE_ENABLE_PREVIEW_MODE=true` หรือเปิดหน้า Configuration แล้วกด **เข้าสู่โหมด Preview**
2. ตรวจว่า banner ระบุชัดว่าเป็นข้อมูลจำลอง และไม่มีข้อมูลถูกเขียนเข้า Supabase
3. เปลี่ยน role จากตัวเลือกในเมนูผู้ใช้ แล้วตรวจว่าหน้าเปลี่ยนตามสิทธิ์ทันที

ข้อมูลตัวอย่างที่ควรพบ:

- ผู้ดูแลระบบ (Preview)
- ครูสมฤทัย ปัญญาดี · ห้อง ป.5/1 · วิทยาศาสตร์
- นักเรียนตัวอย่างคนแรก · ห้อง ป.5/1
- ผู้ปกครองของนักเรียนตัวอย่างคนแรก

## B. Checklist ทุก role

### ผู้ดูแลระบบ

- Dashboard, นักเรียน, ครู, ห้องเรียน, วิชา เปิดได้และไม่ขึ้น error
- เพิ่ม/แก้ไขนักเรียน พร้อม avatar แล้วข้อมูลยังอยู่หลังเปลี่ยนหน้า
- เพิ่มครู ใส่วิชาใหม่เอง บันทึก แล้วกำหนดห้อง/วิชาได้
- เพิ่มผู้ปกครองและเชื่อมกับลูก ตรวจรายชื่อผู้ปกครองรวม
- เปิด **Sync และ Backup** ได้เฉพาะผู้ดูแล
- สร้างงาน เผยแพร่ แก้ไข ยกเลิก และเปิดรายละเอียดรายนักเรียน
- เช็คชื่อ/คะแนน/ตารางเรียน/ประกาศ/รายงาน เปิดและบันทึกได้

### ครู

- เห็นเฉพาะห้องและวิชาที่ได้รับมอบหมาย
- สร้างงาน เผยแพร่ เปลี่ยนห้อง/วิชา และแก้ไขได้เฉพาะขอบเขตของตนเอง
- ส่วนงานมี 3 ส่วน: งานที่มอบหมาย, สถานะการส่ง, ภาพรวมห้อง
- ค้นหานักเรียน กรองส่งช้า/ค้าง/ครบ และเปิดรายละเอียดเชิงลึกได้
- เปิดหน้าการเข้าเรียน เลือกห้อง/วันที่/คาบ แล้วบันทึก มา/สาย/ขาด/ลา
- ให้คะแนน ขอแก้ไข ขยายเวลา และตรวจลิงก์ Google Drive ของนักเรียน
- เห็นรายชื่อผู้ปกครองและลูกที่เกี่ยวข้อง แต่แก้ข้อมูลผู้ปกครองไม่ได้

### นักเรียน

- เห็นเฉพาะข้อมูล ห้อง งาน คะแนน และการเข้าเรียนของตัวเอง
- ไม่มีปุ่มสร้างงานหรือแก้ไขข้อมูลของเพื่อน
- เปิดงาน → วางลิงก์ `https://drive.google.com/...` หรือ `https://docs.google.com/...` → กดส่ง
- ลิงก์ `http://...` และโดเมนอื่นต้องถูกปฏิเสธพร้อมข้อความที่เข้าใจง่าย
- หลังส่งต้องเห็นลิงก์ที่ส่ง สถานะ และเวลาส่งทันที
- ตรวจงานใกล้ครบกำหนด/ส่งช้า/ขอแก้ไข และปรับ avatar ได้

### ผู้ปกครอง

- เห็นเฉพาะลูกที่เชื่อมบัญชีไว้คนเดียว/หลายคนตามจริง
- เห็นภาพรวมการมาเรียน งาน คะแนน ประกาศ และปฏิทินของลูก
- ไม่เห็นข้อมูลเด็กคนอื่น และไม่มีปุ่มแก้ไขเช็คชื่อ/คะแนน/งาน
- เปิดรายละเอียดงานได้ในโหมดอ่านอย่างเดียว

## C. ทดสอบข้อมูลและปุ่มที่มักพัง

| กรณี | ผลที่คาดหวัง |
|---|---|
| กดบันทึกโดยไม่กรอกชื่อ/หัวข้องาน | ไม่บันทึก และมีข้อความใต้ฟอร์ม |
| ใส่คะแนนติดลบ/เกินคะแนนเต็ม | ไม่บันทึก และไม่ทำให้หน้าค้าง |
| เพิ่มข้อมูลซ้ำ | แจ้งเตือนหรือไม่สร้างแถวซ้ำ |
| กดส่งงานซ้ำ | เพิ่ม version ตามจริง ไม่สร้างรายการซ้ำผิดคน |
| วางลิงก์ Drive ไม่ถูกต้อง | หยุดก่อนบันทึก |
| เปลี่ยนห้อง/วิชา | รายการและสถิติเปลี่ยนตามห้อง/วิชาที่เลือก |
| รีเฟรชหลังบันทึก | ข้อมูลยังอยู่ |
| ปิดอินเทอร์เน็ตหลังบันทึก | แสดงสถานะออฟไลน์ ข้อมูลไม่หาย และเข้าคิวซิงค์ |
| เปิดเน็ตกลับมา | กด/รอซิงค์แล้วคิวลดลง และไม่สร้างข้อมูลซ้ำ |
| ผู้ใช้เข้าลิงก์ของ role อื่น | ถูกปฏิเสธหรือ redirect ตามสิทธิ์ |

## D. สั่งรันทดสอบก่อนส่งงาน

```powershell
npm run lint --workspace @smart-classroom/web
npm test --workspaces --if-present
npx tsc --noEmit -p apps/web/tsconfig.app.json --pretty false
npx vite build --configLoader runner --outDir C:\path\to\preview-build
```

เกณฑ์ผ่านรอบนี้: lint ไม่มี warning/error, test ผ่านทั้งหมด, typecheck ผ่าน และหน้า `/login` กับ `/assignments` ตอบ HTTP 200

## E. หมายเหตุ Google Drive

ระบบเก็บลิงก์ Drive พร้อม submission และเวลาไว้ใน Local/Supabase แล้ว ครูเปิดลิงก์จากหน้าตรวจงานได้ นักเรียนต้องตั้งค่าแชร์ไฟล์ใน Google Drive ให้ครูเปิดได้ก่อนส่ง หากต้องการให้ระบบสร้างไฟล์และตั้ง permission อัตโนมัติ ต้องเปิด Google OAuth/Drive API แยกใน production
